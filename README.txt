ARNELIT PHILIP MANI: PERSONAL SITE
==================================

Plain HTML, CSS and one small JS file. No build step.

BEFORE YOU PUBLISH
1. pdfs/Arnelit-Philip-Mani-Pricing-the-Uncertainty-2026.pdf: add the concept paper PDF
   (the Ideas page links to it by that exact name).
2. ideas.html: the "Read on LinkedIn" links point to your LinkedIn activity page.
   Replace each with the direct link to the article or post.
3. ideas.html: add dates to the undated LinkedIn posts if you want them shown.
4. Read each case study in work.html once more for accuracy.

TO PREVIEW
Open index.html in a browser.

TO PUBLISH (free)
Netlify: go to app.netlify.com/drop and drag this whole folder in.
Then add your custom domain under Domain settings.
GitHub Pages also works.

FILES
index.html, about.html, work.html, ideas.html, connect.html
style.css (colours and fonts are variables at the top)
main.js (mobile menu, Ideas filter, footer year)
favicon.svg
images/portrait.jpg (home page), images/portrait-about.jpg (About page)
